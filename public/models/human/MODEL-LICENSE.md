# Face model assets

The `mobilefacenet.json` and `mobilefacenet.bin` files are copied from
`@vladmandic/human-models` version 3.0.4. The package identifies the model as
Sirius-AI MobileFaceNet and distributes the model collection under the MIT
license inherited from its documented sources.

Source: https://github.com/vladmandic/human-models

The `insightface-mobilenet-emore.json` and `insightface-mobilenet-emore.bin`
files come from the archived `vladmandic/insightface` TensorFlow.js model
collection. The repository is MIT licensed and credits the original
InsightFace implementation and its Keras port.

Source: https://github.com/vladmandic/insightface

The remaining model files are distributed with `@vladmandic/human` version
3.3.6 under its MIT license.
