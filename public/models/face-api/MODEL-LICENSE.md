# Face recognition model assets

The model manifests and weight files in this directory are distributed with
`@vladmandic/face-api` version 1.7.15 under the MIT license. They are served as
same-origin application assets and loaded automatically by the browser worker.

Source: https://github.com/vladmandic/face-api

The selected video, frames, face crops and descriptors are not sent to that
source or any other third party.
